# RESONANT Product Requirements

## Purpose

Define what RESONANT is, what it is not, its users, product outcomes, requirements, and acceptance boundaries.

## Currently known project facts

- RESONANT is a smartphone-powered machine condition-change monitoring system.
- Tagline: “Listen before it breaks.”
- It learns a machine-specific known-normal acoustic and vibration baseline and detects subsequent deviation.
- Baseline similarity is not percentage machine health.
- The product must not claim universal machine-health diagnosis.
- Real sensor data is required in real and demo paths.
