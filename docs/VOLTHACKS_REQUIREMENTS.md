# VoltHacks Requirements

## Purpose

Track only verified competition facts and submission obligations relevant to RESONANT.

## Verified event facts

- VoltHacks is presented as an online/public hackathon with hardware, IoT, and AI among
  its themes.
- The published submission deadline is **September 13, 2026 at 5:00 PM EDT**.
- The submission page requests a project name and description, problem statement,
  screenshots or prototype evidence, technologies used, and source-code/GitHub access.
- The official rules require the project or significant new development to be created
  during the event and require a project description, demonstration video or presentation,
  screenshots/photos, and source code when applicable.
- Published judging categories cover innovation/creativity, technical complexity,
  real-world impact, design/functionality, and presentation.

## Submission checklist

- Confirm entrant and team eligibility directly against the organizer's current ruling.
- Confirm final deadline/time zone immediately before submission.
- Provide repository URL and exact submitted commit/tag.
- Record setup and reproduction instructions.
- Capture real microphone permission, waveform, spectrum, and feature response in the demo.
- Show one honest failure/recovery state.
- Distinguish live sensor evidence from offline benchmark evidence.
- State limitations and avoid health/diagnosis claims.
- Provide screenshots and a demo video/presentation.
- Verify every link from a signed-out browser when submission visibility requires it.

## Conflicting official information
