# RESONANT Baseline Engine

## Purpose

Define known-normal commissioning and operating-state-specific baseline creation, storage, versioning, comparison, and invalidation.

## Currently known project facts

- Baselines are machine-specific and represent a verified known-normal condition.
- Subsequent observations are compared with the relevant baseline to detect deviation.
