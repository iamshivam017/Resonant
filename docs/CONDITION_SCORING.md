# RESONANT Condition Scoring

## Purpose

Define baseline similarity and deviation calculations, calibration, interpretation, uncertainty, and user-facing terminology.

## Currently known project facts

- Results describe similarity to, or deviation from, a machine-specific known-normal baseline.
- Baseline similarity must never be presented as percentage machine health.
- Universal diagnostic claims and invented universal thresholds are prohibited.
