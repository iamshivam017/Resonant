# RESONANT UX Specification

## Purpose

Define information architecture, user journeys, product states, interaction requirements, copy rules, accessibility, and design principles.

## Currently known project facts

- The experience should feel like a professional engineering instrument, not a generic AI-generated SaaS dashboard.
- Reliability and demo correctness take priority over decorative polish.
- The UI must not imply universal diagnosis or label baseline similarity as percentage machine health.
